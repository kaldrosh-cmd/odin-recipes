# Odin Recipes

A simple recipe website built as part of **The Odin Project** curriculum. The goal of this project was to practice basic HTML skills, including structuring text, using headings, creating lists, and managing file paths for internal links and images.

## 🍽️ Featured Recipes

The website includes the following recipes:
* **Lasagna** – A classic, hearty Italian baked pasta layer dish.
* **Pork Dumplings** – Flavorful, juicy, and traditional homemade dumplings.
* **Fast English Muffin Pizzas** – A quick, crispy, and customizable snack perfect for busy days.

## 🛠️ Technologies Used

* **HTML5** – For page structure and content.
